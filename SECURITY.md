# Security Policy

## Supported Versions

We actively update and secure the latest major version of ADBPureFlow.

| Version | Supported          |
| ------- | ------------------ |
| v5.0.x  | :white_check_mark: |
| v4.0.x  | :warning: (Legacy) |
| < v4.0  | :x:                |

## Reporting a Vulnerability

We take the security of ADBPureFlow, its binaries, and our users seriously. If you believe you have found a security vulnerability (such as a directory traversal in extraction, a privilege escalation, or command injection), please follow these steps:

1. **Do not open a public issue.** Please report all security vulnerabilities privately.
2. Email your findings to **security@34labs.com**.
3. Include as much detail as possible, including:
   - A descriptive summary of the vulnerability.
   - Step-by-step instructions or proof-of-concept code to reproduce it.
   - Any potential mitigation steps you have identified.

### Our Response Process

- **Acknowledgement:** We will acknowledge receipt of your vulnerability report within 48 hours.
- **Investigation:** We will investigate and reproduce the vulnerability within 5 business days, updating you on our findings.
- **Fix & Patch:** Once confirmed, we will work on a secure fix.
- **Disclosure:** We will release a patched version and coordinate a public security advisory with you, giving you full credit for the discovery (if desired).
